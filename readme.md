# Projet de session du cours 31W

## Agence de voyage


- Ce projet WordPress consiste à créer un site web pour un club de voyage mettant en avant des destinations uniques à travers le monde. Le site inclut une page d'accueil personnalisée, une navigation intuitive, des filtres dynamiques pour explorer les catégories de destinations, et un design adaptatif. Il intègre également un footer interactif avec des informations de contact, des réseaux sociaux, et des liens utiles.
